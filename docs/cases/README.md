# Archived cases for HGWM

Open [index.html](index.html) in a browser; no server, network connection, or installation is required.

Included: 18 cases, 338 step directories indexed, and 337 text logs. All folders are covered. The first, middle, and last available steps were selected with one common rule, without using success or any method score. The selected RGB view, curiosity map, and navigation map are original PNG bytes, not edited or regenerated images. Click images to open their full resolution.

The original collection is about 913 MB. Other frames and GIF animations are omitted to fit the 25 MB supplementary limit. Pickles were not deserialized and are not required by the gallery. The manifest records every original file's size, checksum, and inclusion decision. Text logs are retained with any credential/identity patterns redacted (0 replacements).

The parsed JSON reproduces selected fields from the text logs. It does not infer simulator success or SPL from a goal flag, a locator response, or a directory name. Serialized prior summaries sometimes contain zero node/edge counts; these are preserved as logged and are not assumed to fully describe the hidden runtime graph. No performance aggregate is calculated from this selected collection, and no case is presented as a rerun after code repairs.
